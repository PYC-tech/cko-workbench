# 口述录入示例文本（配内置示例项目）

这份文档里的文本**专为内置示例数据（DEMO-01 · 三代繁育与笼位，30 只鼠）设计**，用来演示语音/口述录入。

用法：打开「口述录入」页 → 把下面代码块的内容**整段复制**粘进文本框 → 点「解析并预览」→ 看确认表 → 点确认入账。

> 演示前建议先看一眼示例项目的原状：鼠只档案里 `307`–`310` 这四只**还没有任何鉴定结果**（对应"未测 ≠ 阴性"这个真实场景）。场景一会把它们补上。

---

## 场景一：第四批仔鼠剪尾鉴定（推荐，最能说明问题）

这四只是 B4 笼里未断奶的 L4 仔鼠，`307`–`310`，此前从未鉴定。口述时说了三件事，正好覆盖程序最核心的三条纪律：

- **KO 那一管是"整批统一陈述"**（"四只都有带"），所以只写在 `@本批默认` 里，用 `~` 的语义；
- **`309` 的 Cre 没跑出来**，明确记为 `?`（未提及），**绝不等于阴性**；
- 结果里 `307` 与 `310` 会被自动判为**目标鼠**（Flox 无带 + KO 有带 + Cre 双带三条同时满足）。

```dictation demo_l4_genotyping
@日期 2026-09-18
@泳道顺序 307 308 309 310
@本批默认 目标基因-KO=阳性
307 | M | 目标基因-Flox=无带 | Cre=双带
308 | F | 目标基因-Flox=2条带 | Cre=1条带
309 | M | 目标基因-Flox=1条带 | Cre=?
310 | F | 目标基因-Flox=无带 | Cre=双带
@备注 307、310 判为敲除鼠；309 的 Cre 没跑出条带，按未提及处理，不要当阴性
```

**预期结果（确认表里应看到）**

| 耳号 | Flox | KO | Cre | 判定 |
|---|---|---|---|---|
| 307 | 无带（明说） | 有带（**本批默认**） | 双带（明说） | 🎯 目标鼠 |
| 308 | 2 条带（明说） | 有带（本批默认） | 1 条带（明说） | — |
| 309 | 1 条带（明说） | 有带（本批默认） | **未提及（虚线框）** | — |
| 310 | 无带（明说） | 有带（本批默认） | 双带（明说） | 🎯 目标鼠 |

## 场景二：复检改判（演示"旧值可追溯"）

`207` 与 `216` 是上月那批的鼠，这次重跑**结论变了**。确认表会明确列出「**将覆盖旧值**」，旧值不会静默丢掉。

```dictation demo_recheck
@日期 2026-09-18
@泳道顺序 207 216
207 | M | 目标基因-Flox=无带 | 目标基因-KO=无带 | Cre=1条带
216 | M | 目标基因-Flox=无带 | 目标基因-KO=有带 | Cre=无带
@备注 这两只是上月那批的重跑，KO 结果跟上次不一样，以这次为准
```

**预期结果**

- `207`：目标基因-KO `有带 → 无带`（**将覆盖旧值**）
- `216`：目标基因-KO `无带 → 有带`（**将覆盖旧值**）
- 其余各项与旧值相同，不算覆盖。

## 场景三：口语原话（演示完整语音链路，不要直接粘）

下面这段是**真实说话的样子**，本身不是程序能解析的格式。它演示的是完整链路：

> 语音转文字 → 连同「口述录入」页的**提示词卡片**一起交给 AI → AI 按卡片格式整理 → 把 AI 的输出粘进解析框。

```口语
那个，今天九月十八号啊，第四批那四只仔鼠，307 到 310，剪尾跑胶了。
Flox 这管：307 是无带，308 两条带，309 一条带，310 也是无带。
KO 那管四只都有带，我就一块儿说了啊。
Cre 跑了三只：307 双带，308 单带，310 双带。309 那管我忘了点样，啥也没跑出来，你可别给我记成阴性。
```

注意最后那句「**别给我记成阴性**」——这正是程序要防的事：没跑出来就是「未提及」，不是阴性。

## 场景四：笼位录入（四种说法）

**① 逐只转入某笼**

```dictation cage_per_rat
@日期 2026-09-18
301 | M | 笼=C5
302 | F | 笼=C6
@备注 这两只换到饲养笼
```

**② 整批进同一笼**（行内写了 `笼=` 就以行内为准）

```dictation cage_batch
@日期 2026-09-18
@笼位 C5
301 | M
302 | M
303 | M | 笼=C1
```

**③ 配种同笼**（只记事件 + 同时改笼，**不会改动父/母字段**）

```dictation cage_cross
@日期 2026-09-18
@配种 209 × 214 B4
```

**④ 从笼里移出 / 清空笼位**

```dictation cage_clear
@日期 2026-09-18
@清空笼位 301 302
303 | M | 笼=
```

> 关键语义：**没提到笼位的鼠，笼位保持不动**（确认表里显示"不改动（现 B4）"，与位点的"未提及"灰虚线**刻意不同**——一个是"我这次没说"，一个是"该测没测"）。

## 场景五：谱系录入

**① 给已有鼠补 / 改父母**（用耳号，只说一个就只改一个）

```dictation pedigree_fix
@日期 2026-09-18
307 | M | 父=209 | 母=210
308 | F | 母=212
```

**② 新生一窝建档**（一次说清：出生日、窝号、父母、笼位、耳号）

```dictation pedigree_newborn
@日期 2026-09-18
@新生 出生=2026-09-10 窝=L5 父=209 母=214 笼=B4 仔=311 312♀ 313
```

`仔=` 里可以给单只标性别（`312♀`）；没标的记为「性别待定」，以后再补。
**父母填不出就留空**（程序会提醒"未提供父本"），不会瞎猜。

**③ 只记配种、不动父母字段**

```dictation pedigree_cross_only
@日期 2026-09-18
@配种 209 × 214
```

## 格式速查（自己写的时候用）

| 写法 | 含义 |
|---|---|
| `@日期 2026-09-18` | 批次日期（也接受 `2026年9月18日`） |
| `@泳道顺序 307 308` | 口述顺序（数据行首格也可以直接写耳号） |
| `@本批默认 目标基因-KO=有带` | 一句话覆盖整批的陈述 |
| `耳号 \| 性别 \| 位点=取值` | 逐只明确念到的结果 |
| 位点`=~`取值 或 位点`~`取值 | 该值来自"整批统一陈述"（两种都认） |
| 位点`=?` 或 位点`?` | **未提及**（绝不等于阴性/无带） |
| `笼=B4` / `笼=` | 转入某笼 / 移出笼位（**不写这格就不动笼位**） |
| `父=209` `母=214` | 用耳号指定父母（**不写就不动父母**） |
| `@笼位 B4` | 整批转笼 |
| `@清空笼位 301 302` | 按耳号清空笼位 |
| `@配种 209 × 214 B4` | 只记配种事件（可同时改笼），不动父母字段 |
| `@新生 出生=… 窝=… 父=… 母=… 笼=… 仔=…` | 新生一窝批量建档 |
| `@备注 自由文字` | 原样保留的备注 |

**容错**（手打常见的写法都认，识别不出会明确提示而不是瞎猜）：全角竖线 `｜`、中文逗号与顿号、`公/母/雄/雌/♂/♀`、`KO：有带`（中文冒号当等号）、`2 条带`（取值里有空格）、`父=209 母=214`（一格写两个字段）、缺 `|` 但第二格像性别的行、数字耳号、`2026年9月18日`。
**会被拒绝的写法**（属硬错，会阻断该行并说明原因）：未知位点、取值认不出、父母耳号不存在、父=母、自引、谱系成环、同一耳号在一段里出现两次。

位点可用**名字、别名或简称**（如 `Flox`、`KO`、`Cre` 都能识别）；取值可用 `double/single/none`、`pos/neg`，也可用中文 `双带/单带/无带`、`有带/无带`。

## 换到自己的项目上演示怎么改

上面三段是配**内置示例项目**（指标名为 `目标基因-Flox` / `目标基因-KO` / `Cre 驱动系`）的。要在**自己的项目**上用，只需处理位点名：

- 把 `目标基因-Flox`、`目标基因-KO` 换成你自己项目里的指标名；或者
- **直接用简称** `Flox` / `KO` / `Cre`——简称与别名在两边都认，实测零错误，最省事。

耳号（如 `307`）在你自己项目里若不存在，程序会按**新鼠建档**处理；想测试"覆盖旧值"，请换成你项目里**已有鉴定结果**的耳号。

想看这段文本能不能解析，随时跑：

```bash
node tests/verify-demo-dictation.js
```
